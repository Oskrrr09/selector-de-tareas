# Roadmap

Las siguientes ideas no son compromisos:

1. Fusionar la pull request de GitHub Pages cuando se apruebe.
2. Seleccionar **GitHub Actions** en Settings → Pages y verificar la URL pública
   desde escritorio y móvil.
3. Recoger feedback de “¿Qué hago ahora?”.
4. Valorar edición y eliminación de tareas.
5. Valorar una migración o importación entre `tareas.json` y `localStorage`.
6. Añadir pruebas de navegador si la interfaz continúa creciendo.
